  1. Normal flow is the default layout of HTML. Block elements stack top to bottom, and inline elements sit next to each other.
  2. Float moves an element to the left or right and lets text wrap around it. You use clear to stop elements from wrapping around floated items and to fix layout problems.
  3. Relative keeps an element in normal flow but lets you move it slightly. Absolute removes it from normal flow and positions it relative to its parent. Fixed removes it from normal flow and keeps it in place on the screen while scrolling.
  4. To make good mobile navigation buttons, use responsive design, Flexbox, larger padding, simple styling, and stack buttons vertically.
