Inline CSS: style written inside an HTML tag, affects one element.

Embedded CSS: style written in the head of one page, affects only that page.

External CSS: style written in a separate file, affects many pages.

Use external CSS because it keeps code clean and easy to change.

A selector tells CSS what to style.
